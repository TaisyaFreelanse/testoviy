# IP Tracker - Отслеживание IP-адресов

Простой скрипт для отслеживания IP-адресов через случайные ссылки с автоматическим созданием публичных ссылок.

## Установка

1. Установите Python 3.7 или выше
2. Установите зависимости:
```bash
pip install -r requirements.txt
```

3. **Установите ngrok** (для публичных ссылок):
   - Скачайте с https://ngrok.com/download
   - Распакуйте и добавьте `ngrok.exe` в PATH
   - Или просто поместите `ngrok.exe` в папку со скриптом

## Использование

1. Запустите скрипт:
```bash
python tracker.py
```

2. Скрипт автоматически запустит ngrok и создаст публичную ссылку, например:
   `https://abc123.ngrok-free.app/track/XyZ789...`

3. Отправьте эту ссылку другу (она выглядит как обычная интернет-ссылка!)

4. Когда друг перейдет по ссылке, в терминале появится его IP-адрес и другая информация

## Особенности

✅ Автоматическое создание публичной ссылки через ngrok  
✅ Ссылка выглядит как обычная интернет-ссылка  
✅ Автоматическое определение IP-адреса посетителя  
✅ Красивая страница-загрузка для маскировки  
✅ Вывод всей информации в терминал  

## Важно!

- Если ngrok не установлен, скрипт будет работать только локально
- Ngrok бесплатный, но требует регистрацию (можно использовать без регистрации с ограничениями)
- После закрытия скрипта (Ctrl+C) ngrok автоматически остановится
